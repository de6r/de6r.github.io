# SecurePass 🔐
Генератор надёжных паролей, который работает прямо в браузере. Никаких серверов, никакой отправки данных — всё локально.

🔗 "Демо:" https://de6r.github.io/

## ✨ Фичи
- 🔒 Генерация через "Web Crypto API" (криптографически стойкая случайность)
- 🧠 "Умная оценка надёжности": учитывает не только длину, но и типы символов
- 🌍 "Мультиязычность" (5 языков)
- 📜 "История генерации" (хранится только в текущей вкладке и стирается при закрытии)
- 🎯 Фильтр "Исключать похожие символы" (0/O, 1/l/I)
- 📋 Кнопка "Копировать" в один клик

## 🛠 Технологии
- HTML5
- CSS3
- JavaScript (Vanilla, без фреймворков)
- Web Crypto API
- sessionStorage для истории

## 🚀 Как запустить локально
Просто открой файл `index.html` в браузере. Никаких сборок и установок не требуется.
